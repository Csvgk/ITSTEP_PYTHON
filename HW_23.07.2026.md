### Завдання 10. Зміни в master, що призведуть до конфлікту

Щоб був конфлікт, треба щоб обидві гілки змінили одні й ті самі рядки. Тому спочатку змінив README.md і src/app.py в newbranch, а потім ті ж рядки по-іншому в master.

```console
$ sed -i '' 's/^# Part 2 project$/# Part 2 project (newbranch version)/' README.md
$ sed -i '' 's/^VERSION = "1.0"$/VERSION = "1.1-beta"/' src/app.py
$ git commit -am "Update README and version in newbranch"
[newbranch 9209401] Update README and version in newbranch
 2 files changed, 2 insertions(+), 2 deletions(-)
$ git switch master
Switched to branch 'master'
$ sed -i '' 's/^# Part 2 project$/# Part 2 project (master version)/' README.md
$ sed -i '' 's/^VERSION = "1.0"$/VERSION = "2.0"/' src/app.py
$ echo 'Контакти: support@example.com' >> docs/manual.txt
$ git diff
```

### Завдання 11. Злиття master у newbranch і розв'язання конфліктів

```console
$ git switch newbranch

$ git merge master

Auto-merging src/app.py

Automatic merge failed; fix conflicts and then commit the result.
$ git status
On branch newbranch
You have unmerged paths.

Changes to be committed:
	modified:   docs/manual.txt

Unmerged paths:
	both modified:   README.md
	both modified:   src/app.py
$ cat README.md
<<<<<<< HEAD
# Part 2 project (newbranch version)
=======
# Part 2 project (master version)
>>>>>>> master
$ cat src/app.py
APP_NAME = "My App"
<<<<<<< HEAD
VERSION = "1.1-beta"
=======
VERSION = "2.0"
>>>>>>> master

print(APP_NAME, VERSION)
```

Git показав конфлікт в двох файлах (позначки `<<<<<<<`, `=======`, `>>>>>>>`). Виправив руками: в README написав спільну назву, а версію залишив з master (2.0). docs/manual.txt змінювався тільки в master, тому злився сам.

```console
$ cat > README.md <<'EOF'
# Part 2 project (master + newbranch)
EOF
$ cat > src/app.py <<'EOF'
APP_NAME = "My App"
VERSION = "2.0"

print(APP_NAME, VERSION)
EOF
$ git add README.md src/app.py
$ git status
On branch newbranch
All conflicts fixed but you are still merging.

Changes to be committed:
	modified:   README.md
	modified:   docs/manual.txt
	modified:   src/app.py
$ git commit -m "Merge master into newbranch, resolve conflicts"
```
