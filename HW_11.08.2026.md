## Завдання 3. Робота з гілкою

```console
$ git switch -c feature-subtraction
Switched to a new branch 'feature-subtraction'
$ echo 'print("Subtraction:", a - b)' >> calculator.py
$ git commit -am "Add subtraction"
[feature-subtraction bf49348] Add subtraction
 1 file changed, 1 insertion(+)
$ git switch main
Switched to branch 'main'
$ cat calculator.py
print("Simple Calculator")
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))
print("Result:", a + b)
```

В main рядка з Subtraction немає, він тільки в гілці feature-subtraction.

## Завдання 7. Випадковий git add

```console
$ echo '# TODO: add multiplication' >> calculator.py
$ git add calculator.py
$ git status
On branch main
Changes to be committed:
	modified:   calculator.py
$ git restore --staged calculator.py
$ git status
On branch main
Changes not staged for commit:
	modified:   calculator.py

no changes added to commit (use "git add" and/or "git commit -a")
$ tail -1 calculator.py
# TODO: add multiplication
```

Файл прибрався зі staging area, а зміна в файлі залишилась. Вона була тільки для перевірки, тому потім її прибрав:

```console
$ git restore calculator.py
```

## Завдання 8. Неправильний коміт

```console
$ echo 'print("Multiplication:", a * b)' >> calculator.py
$ git commit -am "Add multiplication"
[main e30e9bf] Add multiplication
 1 file changed, 1 insertion(+)
$ git log --oneline
e30e9bf Add multiplication
5941c59 Merge branch 'feature-subtraction'
23afb69 Add README
bf49348 Add subtraction
019bc2f Add addition
39a0d74 Add number input
0d06d5d Create calculator
$ git reset --soft HEAD~1
$ git log --oneline
5941c59 Merge branch 'feature-subtraction'
23afb69 Add README
bf49348 Add subtraction
019bc2f Add addition
39a0d74 Add number input
0d06d5d Create calculator
$ git status
On branch main
Changes to be committed:
	modified:   calculator.py
$ tail -1 calculator.py
print("Multiplication:", a * b)
```

`git reset --soft HEAD~1` скасовує останній коміт, але код залишається в файлі. Потім зробив правильний коміт:

```console
$ git add calculator.py
$ git commit -m "Add multiplication feature"
[main 0c21a9f] Add multiplication feature
 1 file changed, 1 insertion(+)
$ git log --oneline
0c21a9f Add multiplication feature
5941c59 Merge branch 'feature-subtraction'
23afb69 Add README
bf49348 Add subtraction
019bc2f Add addition
39a0d74 Add number input
0d06d5d Create calculator
```
