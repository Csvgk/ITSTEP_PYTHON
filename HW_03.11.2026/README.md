# ДЗ 03.11.2026 — Коментарі та підписка на новини

Продовження блогу з ДЗ 29.10.

## Запуск

```bash
python manage.py migrate
python manage.py seed_blog
python manage.py runserver
```

## Що зроблено

1. Модель `Comment` (post, author, text, created_at), міграція `0005`.
2. `CommentForm` — ModelForm тільки з полем `text`. Пост і автор підставляються у view.
3. Коментар додається на сторінці поста кнопкою «Опублікувати», після збереження — редірект назад на пост. Коментувати можуть тільки користувачі, які увійшли.
4. Під постом показуються всі коментарі: автор, дата і текст, нові зверху (`ordering = ['-created_at']`).
5. Валідація: не можна порожній коментар або з одних пробілів, мінімум 5 символів, максимум 500. Помилка показується під формою.

Додатково — підписка на новини:
- модель `Subscriber` (email, created_at), `EmailField` з `unique=True`;
- `SubscribeForm` (ModelForm) у бічній панелі на всіх сторінках;
- повторно підписатися з тим самим email не можна (навіть якщо інший регістр букв);
- після підписки показується «Ви успішно підписалися!»;
- підписники видно в адмінці.
