# Домашнє завдання 29.10.2026 — Django ORM та динамічні маршрути

Продовження блогу з HW_27.10.2026 (копія, оригінальний `New Project/website` не змінювався).

## Запуск

```bash
python manage.py migrate
python manage.py seed_blog      # 5 постів, 3 категорії, 5 тегів, 2 профілі, 3 коментарі
python manage.py runserver
```

Тестові облікові записи створює `seed_blog` (див. `blog/management/commands/seed_blog.py`).

## #1 Головна сторінка — `/`

- Пости беруться через ORM: `Post.objects.select_related('category', 'user').prefetch_related('tags')`.
- Кожен пост — картка з назвою, текстом до 20 слів (`truncatewords:20`), категорією і всіма тегами.
- У бічній панелі — список усіх категорій і тегів.
- Якщо постів немає — «Публікацій поки немає» (`{% empty %}`).

## #2 Сторінка поста — `/post/<int:post_id>/`

- `post_detail` у `views.py`, пост через `get_object_or_404()` (неіснуючий id → 404).
- Шаблон `templates/blog/post_detail.html`: назва, повний текст, категорія, теги.
- Кнопки «Читати далі» на головній і «Назад до блогу» на сторінці поста, усі посилання — через `{% url %}`.

## #3 Профіль автора і коментарі

- `/profile/<int:user_id>/` → `profile_detail`: ім'я, дата реєстрації, дані профілю, список публікацій автора.
  На сторінці поста ім'я автора — посилання на його профіль.
- Модель `Comment` (post, author, text, created_at), міграція `0004_comment.py`, зареєстрована в адмінці.
- На сторінці поста виводяться всі коментарі з автором, текстом і датою.
  Користувач, який увійшов, може додати коментар через форму.

## Перевірка

```text
Головна: 5 карток, у кожній «Читати далі», текст картки = 20 слів, є категорія і теги
/post/1/: є «Назад до блогу», 2 коментарі, посилання на профіль автора
/post/9999/ -> 404, /profile/9999/ -> 404
/profile/<olena>/: «@olena · на сайті з 01.11.2026», 2 публікації
POST коментаря від ivan -> редирект на сторінку поста, коментар збережено
Порожня база -> «Публікацій поки немає»
```
