## 2. Розгортання на PythonAnywhere

Акаунт `Nick1csvgk`. У Bash-консолі:

```console
$ git clone https://github.com/Csvgk/ByteBox.git
$ cd ByteBox
$ python3.13 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
```

## 3. Налаштування Django

На сервері створив `/home/Nick1csvgk/ByteBox/.env`:

```
DJANGO_SECRET_KEY=<новий ключ>
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=nick1csvgk.pythonanywhere.com
DJANGO_CSRF_TRUSTED_ORIGINS=https://nick1csvgk.pythonanywhere.com
```

Ключ згенерував окремо на сервері:

```console
$ python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Далі перевірка, міграції та тестові дані:

```console
$ python manage.py check
System check identified no issues (0 silenced).
$ python manage.py migrate
$ python manage.py seed_shop
$ python manage.py seed_blog
$ python manage.py createsuperuser
```

## 4. Налаштування вебсервера (вкладка Web)

| Параметр | Значення |
|---|---|
| Source code | `/home/Nick1csvgk/ByteBox` |
| Working directory | `/home/Nick1csvgk/ByteBox` |
| Virtualenv | `/home/Nick1csvgk/ByteBox/.venv` |
| WSGI file | `/var/www/nick1csvgk_pythonanywhere_com_wsgi.py` |
| Force HTTPS | Enabled |

WSGI-файл:

```python
import os
import sys

path = '/home/Nick1csvgk/ByteBox'
if path not in sys.path:
    sys.path.insert(0, path)

os.environ['DJANGO_SETTINGS_MODULE'] = 'config.settings'

from django.core.wsgi import get_wsgi_application
application = get_wsgi_application()
```

У `settings.py`:

```python
STATIC_URL = 'static/'
STATICFILES_DIRS = [BASE_DIR / 'static']
STATIC_ROOT = BASE_DIR / 'staticfiles'
MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

```console
$ python manage.py collectstatic --noinput
```

Static files:

| URL | Directory |
|---|---|
| `/static/` | `/home/Nick1csvgk/ByteBox/staticfiles` |
| `/media/` | `/home/Nick1csvgk/ByteBox/media` |

Після цього — **Reload**.

## 5. Тестування

- Сайт відкривається по HTTPS, з `http://` іде редірект на `https://`.
- CSS, іконки (`/static/`) і картинки товарів (`/media/`) завантажуються.
- Пройшовся по всіх посиланнях сайту (головна, каталог з фільтрами і пошуком, сторінки товарів, готові збірки, конфігуратор, блог, кошик, вхід, реєстрація) — 140 сторінок і файлів, усі віддають 200, помилок 404/500 немає.
- Форми працюють: додавання в кошик, пошук і фільтри каталогу, конфігуратор, реєстрація і вхід, коментарі в блозі, адмінка.
- Неіснуюча сторінка віддає звичайну 404 без дебаг-інформації (DEBUG=False).
