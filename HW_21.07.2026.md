### Завдання 7. Перегляд змін

```console
$ sed -i '' 's/Hello, {name}/Hi, {name}!/' utils.py
$ git diff
diff --git a/utils.py b/utils.py
index 8a5b158..bea26a4 100644
--- a/utils.py
+++ b/utils.py
@@ -1,2 +1,2 @@
 def greet(name):
-    return f"Hello, {name}"
+    return f"Hi, {name}!"
$ git add utils.py
$ git diff
$ git diff --staged
diff --git a/utils.py b/utils.py
index 8a5b158..bea26a4 100644
--- a/utils.py
+++ b/utils.py
@@ -1,2 +1,2 @@
 def greet(name):
-    return f"Hello, {name}"
+    return f"Hi, {name}!"
$ git commit -m "Change greeting text"
[main 5ff2e44] Change greeting text
 1 file changed, 1 insertion(+), 1 deletion(-)
```

Різниця:
- `git diff` — показує зміни, які я ще не додав через `git add`. Після `git add` він вже нічого не показує.
- `git diff --staged` — показує те, що вже додано (в staging area) і піде в наступний коміт.

## Рівень 3. Скасування змін

### Завдання 8. Скасування незбережених змін

```console
diff --git a/main.py b/main.py
index 75c3377..e35bf68 100644
--- a/main.py
+++ b/main.py
@@ -2,3 +2,4 @@ print("Hello, Git!")

```

Після `git restore` git diff пустий — зміни зникли.

### Завдання 9. Прибрати файл зі staging area

```console
$ echo 'print("Bye!")' >> main.py
$ git add main.py
$ git status
On branch main
Changes to be committed:
	modified:   main.py
$ git restore --staged main.py
$ git status
On branch main
Changes not staged for commit:
	modified:   main.py

no changes added to commit (use "git add" and/or "git commit -a")
$ tail -1 main.py
print("Bye!")
```

Файл прибрався зі staging area, але сама зміна в файлі залишилась. Потім закомітив її, щоб йти далі.

```console

```

### Завдання 12. Коміт у новій гілці

```console
$ cat >> main.py <<'EOF'


def square(x):
    return x * x


print(square(5))
EOF
$ git diff
diff --git a/main.py b/main.py
index 615fac9..bb3fe6a 100644
--- a/main.py
+++ b/main.py
@@ -3,3 +3,10 @@ print("Git saves project history")
 from utils import greet
 print(greet("Nick"))
 print("Bye!")
+
+
+def square(x):
+    return x * x
+
+
+print(square(5))
$ git commit -am "Add new feature"
[new_feature 3d6533f] Add new feature
 1 file changed, 7 insertions(+)
$ git switch main
Switched to branch 'main'
$ cat main.py
print("Hello, Git!")
print("Git saves project history")
from utils import greet
print(greet("Nick"))
print("Bye!")
```

Чому в main немає змін з new_feature: коміт з функцією square я зробив тільки в гілці new_feature.
Кожна гілка має свою історію, і main досі стоїть на старому коміті. Коли переключаюсь на main,
файли стають такими, як вони є в main. Зміни там з'являться тільки після `git merge`.
